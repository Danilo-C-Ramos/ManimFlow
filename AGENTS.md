# ManimFlow

Chat-driven Manim animation studio for teachers. Design decisions: `docs/design.md`.

## Branches

Work on issues goes to the `develop` branch, never straight to `main`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on the private repo Danilo-C-Ramos/ManimFlow, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
